# System-Level Metrics

| Metric | Definition |
| --- | --- |
| Throughput | Tasks completed per hour |
| Cost per Task | Average $/task |
| Success Rate | Overall % of successful tasks |
| Spec Quality | Hermes task_spec acceptance rate (before executor sees it) |
| Handoff Latency | Time from task creation to executor start |
| Rejection Rate | % of task_specs rejected by executor (need revision) |
| Iteration Count | Average iterations to completion |
| Fallback Rate | % of tasks that needed human intervention |
