# Key Metrics Summary

| Metric | Target | How to Measure |
| --- | --- | --- |
| Success Rate | >90% | successful_runs / total_runs |
| Cost Efficiency | >1.0 | expected_cost / actual_cost |
| Quality Score | >0.8 | LLM-scored or heuristic |
| Avg Iterations | <5 | count of executor calls |
| Avg Time | <60s | Wall-clock time |
| Spec Rejection Rate | <10% | rejected_specs / total_specs |
| Human Intervention Rate | <5% | tasks_needing_human / total_tasks |
| Cost per Task | Decreasing | total_cost / total_tasks |
